# Capability Reference Matrix

## Purpose and Scope

This document inventories every capability-related Markdown and JSON file at the repository root, records who references it, assigns an authority level, and flags migration risks. It is a read-only audit; it does not approve any file move, deletion, or rename.

## Audit Method

1. Enumerated all `*.md` and `*.json` files in the repository root.
2. Classified each file by capability family and material type.
3. Searched the entire repository (excluding `.git` and `node_modules`) for references to each file by basename.
4. Tagged each reference as production code, test, README/Markdown, manifest, script, CI, or other.
5. Assessed authority level and external compatibility risk based on observed references.

External consumers cannot be proven absent by in-repo search; where no evidence exists, risk is recorded as `unknown`.
